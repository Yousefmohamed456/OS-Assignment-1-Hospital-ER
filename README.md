# Hospital Emergency Room Simulation

- Project name: Hospital Emergency Room Simulation.
- Course: Operating Systems.
- Language: Java.
- Description: A multithreaded hospital emergency room simulation using semaphores, a bounded buffer, and producer-consumer synchronization.

## Build and Run

```bash
javac -d out src/*.java
java -cp out Hospital
```

Enter the waiting room capacity, number of doctors, and number of patients when prompted.
